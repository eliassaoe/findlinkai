How to Find a Company's Website in Google Sheets

If you already have a list of company names sitting in a spreadsheet, there's no need to open a dashboard tab and look them up one at a time. The LinkFinder AI add-on runs the same lookup directly on a column, turning hundreds of company names into verified websites without leaving Google Sheets.

Quick walkthrough: enriching a company-name column into websites with the LinkFinder AI add-on · Powered by guidde

A list of company names is only half the picture — the website is what turns "Microsoft" or "Salesforce" into something you can actually visit, scrape, or hand to another tool for further enrichment. Doing this by hand means opening a search engine for every single row, clicking through to confirm you've got the real corporate domain and not a news article or a look-alike site, then copying the URL back into the sheet. For a list of any real size, that's an afternoon lost to tab-switching.

The LinkFinder AI add-on for Google Sheets removes that entirely. Point it at a column of company names, tell it which column to write the results into, and it resolves the whole column to verified websites in place — no exporting, no re-importing, no leaving the sheet you're already working in.

1

Install the LinkFinder AI add-on (one-time)

You only need to do this once per Google account — after that, the add-on is available in every Sheet you open.

1

Install LinkFinder AI from the Google Workspace Marketplace

Search for "LinkFinder AI" in the Google Workspace Marketplace and install it to your Google account. Once installed, it's attached to your account, not to a single spreadsheet, so you won't need to reinstall it for a new sheet. From then on it appears under Extensions → LinkFinder AI → Enrich a column in any Sheet, and the sidebar there asks for your API key from the "API & MCP" tab on linkfinderai.com the first time you use it. For the full screenshot-by-screenshot install walkthrough, see the Google Sheets install guide.

2

Enrich a column with company websites

With the add-on installed, resolving a whole column of company names into websites takes three fields and one click.

1

Choose the "Find Company Website" enrichment

Open Extensions → LinkFinder AI → Enrich a column and select the enrichment for finding a company's website. The sidebar's first field — "What to look up" — is where you point it at your company name column, column B in this sheet.

2

Set the output column and run it

In "Where to put the answer," pick the column where you want the websites written — column D in this example. Click Enrich Column, and every company name in column B is resolved and written into column D, one website per row.

Results land directly in the sheet as they're found, so you can review or filter the column as soon as the run finishes — no export step required.

This is the cheapest lookup on the platform: 1 credit per company. As with every enrichment, a row that finds no match still costs a credit, so a clean, de-duplicated list of company names goes further than a messy one.

Tips for a cleaner run

Use clean, official company names

"Microsoft" matches better than a shortened nickname or a typo'd variant. Pull names from a CRM or a verified list rather than free-typed entries where possible.

Drop legal suffixes

Trim "Inc.", "LLC", "Ltd.", and similar suffixes before running the enrichment. They rarely help the match and occasionally confuse it.

De-duplicate before a big run

Since every row costs a credit regardless of outcome, sort and remove duplicate company names first — it's the single easiest way to cut wasted spend.

Know the run limit

Google stops any add-on execution at 6 minutes, which caps a single run at roughly 400-600 rows for a fast lookup like this. Split a larger list into batches, running each one separately.
