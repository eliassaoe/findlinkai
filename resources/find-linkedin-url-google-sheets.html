How to Find LinkedIn URLs From Names in Google Sheets

If your leads already live in a spreadsheet, there's no reason to copy names into a separate dashboard one at a time. The LinkFinder AI add-on for Google Sheets runs the same LinkedIn URL lookup right inside Extensions, so a whole column of names turns into a column of profile links without ever leaving the sheet.

Full walkthrough: installing the LinkFinder AI add-on and enriching a column of names with LinkedIn URLs in Google Sheets · Powered by guidde

The regular way to find a LinkedIn URL is to open the LinkFinder AI dashboard, type in a name and company, and copy the result back into your spreadsheet — fine for one lookup, painful for two hundred. The Google Sheets add-on removes that round-trip entirely: it reads names straight out of the columns you already have and writes the matching LinkedIn URL back into the sheet, row by row, without ever exporting a CSV.

This guide covers the two things you need: installing the add-on once from the Google Workspace Marketplace and connecting it with your API key, then running it to enrich a real column of leads. If you'd rather not install anything in Sheets at all, the plain dashboard walkthrough at /resources/find-linkedin-url covers the single-lookup and CSV-upload paths instead.

On this page

  1. Install and connect the LinkFinder AI add-on
  2. Enrich a column with LinkedIn URLs
1

Install and connect the LinkFinder AI add-on

This is a one-time setup per Google account. Once installed, the add-on is available in Extensions in every Sheet you open.

1

Open the integrations section

From your LinkFinder AI dashboard, go to the integrations section where the Google Sheets add-on is listed alongside the other ways to connect the tool to your workflow.

2

Click "Install the add-on"

This hands off to the Google Workspace Marketplace listing for LinkFinder AI for Google Sheets, where the add-on's details and permissions are shown before you install.

3

Open the listing and install it

Click into the add-on's details, then continue through the install flow and confirm with "Install" when prompted.

4

Sign in and authorize the add-on

Sign in with the Google account you use for Sheets, then click "Select all" on the permissions screen and turn access on. This is a Google Marketplace consent step, not something LinkFinder AI-specific — it's what lets the add-on read and write cells in a sheet you open it in.

5

Find it in Extensions and get your API key

Open a Google Sheet, click Extensions, and LinkFinder AI now appears in the list. Before running anything, switch back to linkfinderai.com, open API & MCP, and copy your API key — the add-on needs it to run lookups against your account.

2

Enrich a column with LinkedIn URLs

With the add-on installed and your API key in hand, this is the part you'll repeat every time you have new leads to enrich.

1

Open "Enrich a column" and paste your API key

Back in your Sheet, go to Extensions → LinkFinder AI → Enrich a column. The sidebar opens with a settings step for your API key the first time you use it — paste in the key you copied and it's remembered for future runs.

2

Point the sidebar at your Full Name column

The sidebar's "1. What to look up" step asks which column holds the name. Select your Full Name column — this is the required field the lookup runs on.

3

Add the Company Name, Location, and Job Title columns

Under "2. Where to read it from", map the rest of your columns: Company Name, Location, and Job Title. In this example the sheet has Microsoft in the company column, USA for location, and CEO as the job title — each field narrows the match further for names that are common.

Company name is the single biggest factor in match accuracy. Location and job title help narrow down common names, but if you can only fill in one extra field, make it company.
4

Set the output column

Under "3. Where to put the answer", choose (or create) a column for the LinkedIn URL — this is where the add-on writes its results, one per row.

5

Click "Enrich column" and check the results

Click "Enrich column" to run the lookup on every row. The add-on works through the sheet and writes a LinkedIn URL into the output column for each name it matches; reopen Extensions → LinkFinder AI at any point to check progress or run it again.

Every row that runs costs credits whether or not a match is found — a miss is charged the same as a hit. Rows that already have a value in the output column are skipped automatically, so re-running "Enrich column" on the same sheet only charges for the rows still blank.

Tips for running the add-on well

De-duplicate before running

Since every processed row costs credits, remove duplicate names before clicking Enrich column — a repeated row is a repeated charge for the same answer.

Add location for common names

If your list has a lot of "John Smith"-type names, fill in the Location column too. It's an easy way to cut down on wrong matches without adding much manual work.

Know the run limit

Google kills any add-on run at 6 minutes — roughly 400-600 rows for a LinkedIn URL lookup. Split larger lists across a couple of runs.

Re-run to fill in gaps

Answered rows are skipped automatically, so if a run stops partway or a few rows come back blank, just click Enrich column again — you won't be charged twice for the same row.
