Find Lead Email Addresses Using LinkFinder AI

This video shows how to find email addresses from LinkedIn profile URLs using LinkFinder AI.

Go to www.youtube.com

1. Access LinkFinder AI Website

Click on the first link in the video description, which redirects to linkfinderai.com.

2. Start Free Trial Account

Click the Start Free Trial button to create a free account on LinkFinder AI.

3. Select Input Data Type

Select the input data type from options including Company Name, Company Domain, Email Address, and LinkedIn Company URL.

4. Choose LinkedIn Profile URL Input

Choose LinkedIn Profile URL as the input data type for your search.

5. Select Output Data Type

Click to select the output data type, such as LinkedIn Profile Data, Phone Number, or Email Address.

6. Choose Email Address Output

Choose Email Address as the desired output type to retrieve lead emails.

7. Enter LinkedIn Profile URL

Click the field to enter the LinkedIn Profile URL for your lead.

8. Fill LinkedIn Profile URL

Enter the lead's LinkedIn profile URL into the input field.

9. Enrich Data Request

Click the Enrich Data button to find the lead's email address from the LinkedIn profile URL.

10. View Retrieved Email Address

Click on the displayed email address to view the lead's contact information.

11. Access Bulk Upload Feature

Click the Upload CSV (bulk) button to process multiple LinkedIn profile URLs at once.

12. Select CSV File

Click Select File to choose a CSV file containing LinkedIn profile URLs of your leads.

13. Process Uploaded Items

Click Process items to start enriching the uploaded LinkedIn profile URLs with email addresses.

14. Confirm Processing of Items

Click Process 1 items again to confirm and continue the enrichment process.

15. Export Enriched Data

Click the Export button to download the enriched data as a CSV file.

16. Open API Access Section

Click the API Access option to explore programmatic access to LinkFinder AI features.

17. View API Documentation

Click View API Docs to review the available API endpoints and usage instructions.

18. Access B2B Data Lookup API

Click the B2B Data Lookup section within the API documentation for relevant endpoints.

19. Select LinkedIn to Email API

Click the linkedin_profile_to_email API endpoint to convert LinkedIn URLs to email addresses.

20. Review API Call Example

Click the example curl command showing how to POST a LinkedIn URL and receive an email address.
