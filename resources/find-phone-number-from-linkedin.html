Discover Phone Numbers Using LinkFinder AI Demo

This demo shows how you can find any lead's phone number using their name. It highlights the two-step process of retrieving LinkedIn URLs and phone numbers efficiently.

Go to www.youtube.com

1. Access Linkfinder AI Website

Click the Linkfinder AI URL to navigate directly to the Linkfinder AI homepage.

2. Switch To Linkfinder AI Site

Switch to the "linkfinderai.com" website to begin the data enrichment process.

3. Open Data Type Dropdown

Click the "Select data type" dropdown to choose the type of data you want to enrich, such as Company Name or Email Address.

4. Choose Data Type

Fill the data type field by selecting the appropriate option for your search criteria.

5. Open Output Type Dropdown

Click the "Select output type" dropdown to specify the type of output you want, like LinkedIn Profile URL or Verified Email.

6. Select Output Type

Fill the output type field by choosing the desired output format for your data enrichment.

7. Focus On Full Name Input

Click the "Enter Full Name" input field to provide the lead's full name for the search.

8. Input Name Fragment

Fill the input field with a partial name fragment to start the search process.

9. Enter Full Lead Name

Fill the input with the full lead name, such as "Sarah Johnson", to refine the search.

10. Select Company Name Field

Click the "Company Name" field to specify the company associated with the lead.

11. Input Company Name

Fill the company name field with the lead's company, for example, "Salesforce".

12. Initiate Data Enrichment

Click the "Enrich Data" button to start the data enrichment process based on the provided inputs.

13. View Profile Data Found

Click the notification showing "Profile Data Found! ✨ Sarah Johnson LinkedIn Profile URL" to review the results.

14. Open LinkedIn Profile

Click the LinkedIn profile URL to view the lead's LinkedIn page.

15. Access LinkedIn Profile

Click the LinkedIn profile URL again to ensure access to the lead's profile page.

16. Open Data Type Dropdown Again

Click the "Select data type" dropdown to choose a different data type for enrichment.

17. Choose New Data Type

Fill the data type field with the new selection to continue the enrichment process.

18. Open Output Type Dropdown Again

Click the "Select output type" dropdown to specify the output format for the new data type.

19. Select New Output Type

Fill the output type field with the desired format such as LinkedIn Profile Data or Phone Number.

20. Focus On LinkedIn URL Input

Click the "Enter LinkedIn Profile URL" input field to provide the lead's LinkedIn profile link.

21. Input LinkedIn Profile URL

Fill the input with the lead's LinkedIn profile URL to proceed with phone number lookup.

22. Click Enrich Button

Click here to enrich the data and find the lead's phone number using the LinkedIn profile URL.

23. View Phone Number Found

Click the notification showing "Profile Data Found! ✨ LinkedIn URL Phone Number +13175002454" to see the phone number result.

24. Access API Access Section

Click the "API Access" section to explore API integration options for LinkFinder AI.

25. View API Documentation

Click "View API Docs" to review the API documentation and usage details.

26. Open B2B Data Lookup

Click "B2B Data Lookup" to access specific API endpoints for business data retrieval.

27. Select Full Name To LinkedIn API

Click "lead_full_name_to_linkedin_url" to see the API call for finding LinkedIn URLs from full names.

28. View API Curl Command

Click the curl command example showing how to POST a request to the LinkFinder AI API with authorization.

29. Review API Endpoint Details

Click "POST lead_full_name_to_linkedin_url Sync" to understand how to find a person's LinkedIn URL from their full name.

30. Select LinkedIn To Phone API

Click "POST linkedin_profile_to_phone Sync" to learn how to find a phone number from a LinkedIn profile URL.

31. View Phone Lookup Curl Command

Click the curl command example for the phone number lookup API using LinkedIn profile URLs.

32. Review Phone Lookup API Details

Click "POST linkedin_profile_to_phone Sync" to finalize understanding of the phone number retrieval process via API.
