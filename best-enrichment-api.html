Frequently asked questions
What makes the best enrichment API?
The best enrichment API combines high data accuracy, real-time updates, fast response times, broad coverage, and effortless integration. LinkFinder AI delivers 95% accuracy, sub-100ms responses, 10M+ indexed companies, and REST endpoints that work with any language or no-code platform — so you spend time using data, not chasing it.
What data can the enrichment API return?
From a single email, domain, or LinkedIn URL you get company firmographics (employee count, industry, website, location, founding year), LinkedIn company and personal profiles, verified business emails with status, phone numbers, and key decision-maker details — all in one response.
How accurate is the enrichment data?
We maintain 95% data accuracy through real-time updates and multiple-source verification. Records are continuously validated and refreshed, and each enrichment response includes a match confidence score so you can set your own quality threshold.
How much does it cost to get started?
You can start for free with an API key and pay only for what you use. Standard plans include generous request volumes with burst capacity, and enterprise pricing is available for high-volume teams. No long-term contract is required to begin enriching data.
What's the rate limit for the enrichment API?
Standard plans include 1000 requests per minute with burst capacity up to 2000 requests. Enterprise customers can request higher limits based on their specific volume and use case.
Is the enrichment API compliant with privacy regulations?
Yes. We're SOC 2 compliant and follow GDPR guidelines for all data processing. All data is sourced from publicly available information, and we provide opt-out mechanisms for individuals and companies when required.
