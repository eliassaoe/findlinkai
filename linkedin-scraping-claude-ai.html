Perform LinkedIn Scraping Using LinkFinder AI MCP

In this video we are going to see how you can do linkedin scraping with claude code using linkfinder ai MCP

Go to www.youtube.com

1. Access LinkFinder AI Website

First, click on the first link in the video description to be redirected to LinkFinder AI.

2. Switch to LinkFinder AI Tab

Switch to the "linkfinderai.com" tab to continue.

3. Start Free Trial Account

Click "Start Free Trial" to create a free account on LinkFinder AI.

4. Open API and MCP Section

Once you've created a free account on LinkFinder AI, go to the API and MCP section to find your MCP URL.

5. Access MCP URL Link

Click here to access the MCP URL details.

6. Select User Profile

Click "profile" to access your profile.

7. Open Settings Menu

Click "settings" to open the settings menu.

8. Access Connectors Section

Click "Connectors" to manage your connectors.

9. Add New Connector

Click "add" to add a new connector.

10. Add Custom Connector

Click "add a custom connector" to add a custom connector.

11. Select Name Field

Click "Name" to enter the connector name.

12. Enter Connector Name

Fill "Linkfinder AI" as the connector name.

13. Select MCP Server URL Field

Click "URL" to enter the MCP server URL.

14. Enter MCP Server URL

Fill the MCP server URL from LinkFinder AI.

15. Add Connector

Click "Add" to add the connector.

16. Access Connector Settings

This will add linkfinder ai mcp to your claude code

17. Open Connector Details

Click here to send a query to claude code for linkedin scraping

18. Enter Scraping Query

Fill "scrape bill gates linkedin profile with linkfinder ai mcp" to start scraping.

19. Access Profile Details

We can see that claude code retrieved all Linkedin data about bill gates using linkfinder ai.

20. Fill Additional Fields

Fill here to enter another query. Now we are going to ask claude code to scrape microsoft linkedin page

21. Navigate Messages

Here we can see full linkedin company data about microsof

22. Click to Continue

Click here to continue with another query. we are going to ask claude code to find bill gates email address now

23. View Found Email

We can see that it found the linkedin email adress for bill gates .

24. Click to Proceed

Click here to continue with another query

25. Enter Employee Query

Fill "find 10 employee that are C_suite from the company tesla" to search for C-suite employees at tesla

26. Navigate Messages

We can see that claude code retrieved 10 employees from the linkedin company page of tesla
