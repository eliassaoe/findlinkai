Discover LinkedIn URLs With LinkFinder AI

Find any lead's LinkedIn URL using only their name. This demo showcases how LinkFinder AI simplifies lead enrichment and data accuracy for your business needs.

Go to linkfinderai.com

1. Access LinkedIn URL Finder

You go on LinkFinder AI and you click on LinkedIn profile URL. Here, you're going to see multiple input fields.

2. Select Full Name Field

The first input is for the lead full name. You click Enter Full Name to start.

3. Enter Lead Name

For example, we can enter Bill Gates.

4. Select Company Name Field

Then you have a second input for the company name of this lead. You click Company Name.

5. Enter Company Name

For Bill Gates, this will be Microsoft.

6. Select Location Field

You can also enter the location for the lead by clicking Location optional.

7. Enter Location

Here, we fill USA as the location.

8. Select Job Title Field

Next, click Job Title optional to specify the lead's job title.

9. Enter Job Title

Fill CEO as the job title of this lead.

10. Start Data Enrichment

You click on Enrich Data to start finding the LinkedIn URL for Bill Gates using the inputs provided.

11. Upload Bulk CSV

To find LinkedIn URLs for multiple people, you can use the Upload CSV (bulk) option.

12. Select CSV File

Click Select File to choose your CSV list containing lead information.

13. Preview CSV Data

After uploading, you can preview the names, companies, locations, and job titles for each person in your CSV.

14. Process CSV Items

Click Process 5 items to start scraping LinkedIn URLs for each person in your CSV list.

15. Select Lead Data Format

Click Lead Full Name + Company Name to specify the data format for enrichment.

16. Export Results

Click Export to download the enriched LinkedIn URLs as a CSV file.

17. Access API Section

You can go to API Access to find LinkedIn URLs programmatically using the LinkFinder API.

18. Open API Documentation

Click View API Docs to explore the API documentation and available endpoints.

19. Select B2B Data Lookup

Within the documentation, click B2B Data Lookup to find LinkedIn URLs from lead names and companies.

20. Choose LinkedIn URL API

Click Find a person's LinkedIn URL from their full name and company to see the API call details.

21. View API Call Example

Review the cURL example showing how to make a POST request to find LinkedIn URLs using your API key.

22. Inspect cURL Command

Click the cURL command snippet to understand the request structure for the API call.
