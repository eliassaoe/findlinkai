Discover CEO Emails With LinkFinder AI Data Enrichment

This video demonstrates how you can find the email address for any CEO from any company. It highlights the powerful data enrichment features of LinkFinder AI that simplify this process.

Go to linkfinderai.com

1. Select Input Data Type

First, select the type of input data such as Company Name, Company Domain, Email Address, or LinkedIn Company URL.

2. Specify Input Data Type

Specify the input data type to guide the enrichment process effectively.

3. Choose Output Data Type

Next, choose the output type, for example, Company Employees List, to define the desired results.

4. Confirm Output Selection

Confirm the selection of the output type to proceed with data enrichment.

5. Select Employee Levels

Select the employee levels such as Founder, Owner, C-Suite, Director, or Partner to filter results.

6. Specify Seniority Levels

Specify the seniority levels to focus on executives relevant to your search.

7. Set Number of Results

Set the number of results you want to retrieve, for example, 25.

8. Enter Desired Result Count

Enter the desired number of employees to be returned, such as 10.

9. Access Company Domain Field

Access the field to enter the company domain for which you want to find employees.

10. Input Company Domain

Input the company domain, for example, tesla.com, to target your search.

11. Initiate Data Enrichment

Click the Enrich Data button to start retrieving employee information based on your criteria.

12. Review Employee Details

Review detailed information for each employee found in the list.

13. Access LinkedIn Profile

Click the LinkedIn URL to access the profile of a specific employee, such as Fiona Chen.

14. Check Employee Title

Check the employee's title, for example, Chief Human Resources Officer, to confirm their role.

15. Select New Input Data Type

Select a new input data type to perform another enrichment, such as LinkedIn Profile URL.

16. Specify New Input Type

Specify the new input data type to continue with the enrichment process.

17. Choose New Output Type

Choose the output type like LinkedIn Profile Data, Phone Number, or Email Address for detailed results.

18. Confirm New Output Type

Confirm the selection of the new output type to proceed.

19. Access LinkedIn URL Field

Access the field to enter the LinkedIn Profile URL for the employee you want to enrich.

20. Input LinkedIn Profile URL

Input the LinkedIn Profile URL, for example, http://www.linkedin.com/in/fiona-chen-6785ba97.

21. Start Profile Data Enrichment

Click Enrich Data to retrieve profile information based on the LinkedIn URL provided.

22. View Profile Data Found

The system displays profile data found, including email addresses like sarah.johnson@salesforce.com.

23. Access API Section

Navigate to the API Access section to explore programmatic integration options.

24. Open API Documentation

Click View API Docs to review detailed API documentation and usage guidelines.

25. Select B2B Data Lookup

Select the B2B Data Lookup section to find relevant API calls for business data.

26. Choose Company Enrichment API

Choose the Company Enrichment API to access company-specific data retrieval methods.

27. Select Employee Lookup Endpoint

Select the company_domain_to_employees endpoint to fetch employee data by company domain.

28. Review API Request Example

Review the example curl command demonstrating how to post a request to the API with authorization.

29. Select Seniority Parameter

Select the seniority parameter to filter employees by their level within the company.

30. Return to B2B Data Lookup

Return to the B2B Data Lookup section to explore additional API calls.

31. Select Profile to Email API

Select the linkedin_profile_to_email API to convert LinkedIn profiles into email addresses.

32. View Profile to Email API Example

View the curl command example for the linkedin_profile_to_email API including authorization and data payload.
