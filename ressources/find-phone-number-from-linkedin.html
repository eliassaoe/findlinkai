Find Phone Numbers From LinkedIn Profiles Using LinkFinder AI

This demo shows how you can find phone numbers from LinkedIn profile URLs using LinkFinder AI. You'll see how to use free credits to enrich contact data efficiently.

Go to www.youtube.com

1. Access LinkFinder AI Website

First, go to the description of this video and click on the first link to be redirected to the LinkFinder AI website.

2. Switch To LinkFinder AI Site

You will be redirected to the LinkFinder AI website where you can start your free trial.

3. Start Free Trial Account

Click on Start Free Trial to create a free account and begin using the service.

4. Receive Free Credits

Once you've created your free account, you'll be granted credits that you can use to find phone numbers from LinkedIn profiles for free.

5. Select Input Data Type

Set the input data type to LinkedIn profile URL to specify the kind of data you will provide.

6. Choose LinkedIn Profile URL

Choose LinkedIn profile URL as the input data type for your lookup.

7. Select Output Data Type

Next, select the output data type as phone number to get the contact information you need.

8. Confirm Phone Number Output

Confirm that the output type is set to phone number for accurate results.

9. Enter LinkedIn Profile URL

Click the field to enter the LinkedIn profile URL of the lead you want to find the phone number for.

10. Input Example LinkedIn URL

Fill in an example LinkedIn profile URL such as https://www.linkedin.com/in/splahjohnson to start the lookup.

11. Initiate Data Enrichment

Click Enrich Data to begin scraping and finding the phone number associated with the LinkedIn profile URL.

12. View Found Profile Data

Once the process completes, you will see the profile data found including the phone number linked to the LinkedIn profile.

13. Upload CSV For Bulk Lookup

If you want to perform multiple lookups, click Upload CSV to process a list of LinkedIn profile URLs in bulk.

14. Select CSV File

Click Select File to choose the CSV file containing the LinkedIn profile URLs you want to enrich.

15. Process Bulk Items

Click Process 3 items to start enriching phone numbers for each lead in your CSV file.

16. Review Bulk Enrichment Results

After processing, review the results showing phone numbers found for each LinkedIn profile URL in your list.

17. Export Enrichment Data

You can export the enriched data as a CSV file for your records or further use.

18. Access API Section

Navigate to the API Access section to explore programmatic ways to use LinkFinder AI's data enrichment.

19. Open API Documentation

Click View API Docs to see detailed instructions on how to integrate with LinkFinder AI's API.

20. Select B2B Data Lookup API

Choose the B2B Data Lookup API to find phone numbers from LinkedIn profiles programmatically.

21. Choose LinkedIn Profile To Phone API

Select the POST linkedin_profile_to_phone API endpoint which finds a person's phone number from their LinkedIn profile URL using one credit.

22. View API Call Example

Review the example curl command showing how to call the API with your authorization key and LinkedIn profile URL input.
